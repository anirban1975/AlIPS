# Lesson Plan

A plan that is a list of topics is not a plan. A plan is a sequence of
things *students do*, with checkpoints that tell you whether it worked
while there is still time to fix it.

## Ask first, if not supplied

- Grade/class and subject
- Topic, and the chapter or syllabus reference
- Period length (assume 40 minutes if unstated)
- Class size and ability spread
- What they already covered last lesson
- Any board-specified learning outcomes to hit

Ask for the missing ones in a single short question, not one at a time.
If the user says "just make reasonable assumptions", do so and state them
in one line at the top.

## Output structure

### 1. Header block
Class · Subject · Topic · Duration · Date · Syllabus reference

### 2. Learning objectives — 2 to 3, no more

Write them so you could *test* whether they happened. Use the verb ladder:

| Level | Verbs | Example |
|---|---|---|
| Recall | state, list, define, label | "State the three states of matter" |
| Understand | explain, describe, classify | "Explain why ice floats on water" |
| Apply | solve, calculate, demonstrate | "Calculate density given mass and volume" |
| Analyse | compare, distinguish, infer | "Compare evaporation and boiling" |
| Create | design, construct, propose | "Design an experiment to show..." |

Never write "Students will understand water." Understand how, to what
depth, shown by what? A good objective already tells you how you will
assess it.

### 3. Prior knowledge assumed
One line. What must already be in place, and what to do in the first two
minutes if it isn't.

### 4. Materials and preparation
Include the low-tech fallback. Projectors fail.

### 5. The lesson, minute by minute

Every block gets a time, a teacher action, and a student action.

```
0-5    HOOK          Teacher: [demo / question / image / story]
                     Students: [predict / discuss in pairs / write a guess]

5-15   INPUT         Teacher: [explains, models, worked example]
                     Students: [annotate, follow along, copy the model]

15-30  PRACTICE      Students: [do the thing, independently or in pairs]
                     Teacher: [circulates — watching for X]

30-37  CHECK         [see formative check below]

37-40  CLOSE         Students: [state one thing learned / exit ticket]
```

**The hook must create a question in the student's head**, not announce
the topic. "Today we will learn about density" is not a hook. Two objects
of the same size, one floats, one sinks — *why?* — is a hook.

**No block longer than 15 minutes of teacher talk.** If your input section
runs to 20 minutes, break it with a turn-and-talk or a quick question.

### 6. Differentiation — all three tiers, always

| Tier | Provide |
|---|---|
| **Support** | A scaffold: worked example to copy, sentence starters, fewer steps, a word bank, a partner |
| **Core** | The main task as designed |
| **Stretch** | Not *more* of the same — a *harder kind*: an edge case, an explanation task, a "what if we changed X", teaching it to someone else |

Stretch work that is just ten more of the same sums is busywork, and fast
students learn that finishing early is punished.

### 7. Formative assessment — how you will know

Name the specific check and what you will do about each result.

Good checks: exit ticket (one question on a slip), mini-whiteboards all
raised at once, cold-call three students at different ability levels,
thumbs 1-5, one worked problem on the board with a deliberate error to find.

Then: *"If more than a third get it wrong, I will [re-teach with X next
lesson / stop and model again now]."* A check with no planned response is
decoration.

### 8. Common misconceptions for this topic
List 2-3 specific wrong ideas students actually hold about this topic, and
the sentence you will use to confront each. This is the part most plans
skip and the part that most improves the lesson.

### 9. Homework
Purpose in one line (practice / prepare / extend), the task, realistic
time, and how it will be checked.

### 10. If time runs short / If time is left over
Two lines. Which block to cut, and what to do with a spare five minutes.

## Quality bar

Before finishing, check: could a substitute teacher pick this up and run
it? If any step says only "discuss the topic", it is not finished — say
what the question is and how long they discuss it for.
